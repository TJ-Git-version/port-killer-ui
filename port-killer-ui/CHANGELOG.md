# 更新日志（Changelog）

本项目所有重要变更都会记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [语义化版本规范](https://semver.org/lang/zh-CN/)。

## [1.0.0] - 2026-08-21

### 功能（Features）

- 跨平台桌面应用：支持 Windows、macOS、Linux 三平台打包
- 现代暗色主题界面：卡片式布局、悬停 / 入场 / 弹窗动画、Toast 结果反馈
- 输入端口号或点击常用端口快捷按钮，实时查询占用进程（PID、进程名、协议、本地地址、状态）
- 勾选 / 全选 / 点击整行切换勾选，一键强制关闭选中进程（`taskkill /PID /F`）
- 权限不足时一键「以管理员身份重启」（UAC 提权）
- 常用端口快捷入口：80 / 443 / 3000 / 5173 / 3306 / 6379 / 27017
- 自动忽略 PID=0 的残留连接（TIME_WAIT 等），避免误报端口仍被占用

### 修复（Bug Fixes）

- 修复同一进程多地址监听（如 0.0.0.0 与 127.0.0.1）时列表重复显示的问题（按 PID + 协议 + 状态去重）
- 修复 TIME_WAIT 残留连接（PID=0）被当作可关闭进程、点击关闭时报错的问题
- 修复以管理员身份重启时，程序路径含空格 / 特殊字符导致启动失败的问题
- 修复普通权限下关闭系统级进程时无明确错误提示的问题
- 修复非法端口输入（0、超出范围、非数字）时无校验提示的问题

### 相对 tkinter 版（v1）的改进

- 界面从原生控件升级为现代暗色主题，交互更流畅
- 系统命令只在主进程执行，渲染进程无 Node.js 权限，安全性更高
- 支持 GitHub Actions 三平台自动构建与 GitHub Release 自动发布
- 内置核心逻辑单元测试与界面自动化验证脚本
